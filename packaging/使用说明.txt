写心 · HeartWrite Studio v1.0.0
现代跨端小说创作工作台 · 2026-11-24

启动方式
解压整个文件夹，双击 HeartWrite.exe。
请把 WebView2Loader.dll 与 HeartWrite.exe 放在同一文件夹内。
运行环境：64 位 Windows 10/11，以及 Microsoft Edge WebView2 运行时。

数据目录与备份
首次启动可自由选择稿件保存目录（默认建议「文档\写心稿件」），后续可在「设置 → 本地存储」更换位置。
整个数据目录拷走就是完整备份，也可在应用内导出 JSON 完整备份、EPUB 电子书、TXT、Markdown 与 HTML。

v1.0.0 主要新特性
1. Material Design 3 + 二次元主题系统：内置樱花物语、星夜物语、苍蓝初音、黄昏校园等 8 套配色与实时全屏预览。
2. 跨端同步中心：支持局域网同步（自动发现 + 6 位 PIN + 扫码配对）与 WebDAV 云同步（坚果云 / Nextcloud / AList），统一三向差异合并，冲突自动保存历史版本、零丢稿。
3. ✨ AI 写心酱创作助手：支持 DeepSeek / 硅基流动 / OpenAI / Claude / Gemini / 本地 Ollama 流式生成、深度思考折叠、6 项小说专属技能与选区浮动条（密钥仅存本机）。
4. 现代小说编辑体验：可折叠章纲便签、快捷中文标点栏、打字机居中模式、阅读预览模式、专注模式与番茄钟。

常用快捷键
Ctrl+S 保存；Ctrl+Shift+S 快照；Ctrl+Shift+F 一键排版；Ctrl+Shift+A 写心酱 AI；
Ctrl+Shift+Y 同步中心；Ctrl+Shift+P 阅读预览；Ctrl+F 全文搜索；Ctrl+H 查找替换；
F9 目录栏；F10 素材/AI 栏；F11 专注模式；Esc 关闭弹层或退出专注。
